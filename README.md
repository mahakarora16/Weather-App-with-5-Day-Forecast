# Weather App 🌤

This is a weather application built using JavaScript that provides current weather information along with a 5-day forecast for any city. The app uses the OpenWeatherMap API to fetch weather data and display it with a clean and responsive design.

### Features:
- **Real-time Weather**: Displays current weather information for any city.
- **5-Day Forecast**: View detailed weather for the next 5 days with temperature, weather conditions, and icons.
- **Light & Dark Mode**: Toggle between light and dark mode for better usability.
- **Dynamic Background**: Background changes based on the time of the day (sunny during the day, starry at night).
- **Recent Search History**: Keeps track of recently searched cities, making it easy to access previous searches.
  
### Technologies Used:
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API (for fetching weather data)

### How to Use:
1. Clone this repository.
2. Get your API key from [OpenWeatherMap](https://openweathermap.org/).
3. Replace the `apiKey` in `script.js` with your own API key.
4. Open `index.html` in your browser to use the app.
